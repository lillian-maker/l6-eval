# l6-eval

L6（规则先行的经营问题求解）评测用题的清理记录。

## 内容

- `cleanup/问题台账_all.csv`：逐条问题台账。列：tid、任务、rubric 编号或 golden 位置、问题类别、严重度、问题描述、核实方式、修正建议、是否需出题方确认、第 1 轮评审 note 是否提到。
- `cleanup/修正稿_*.md`：每题修正后的评分细则与标准答案文字。
- `cleanup/耗时_*.csv`：每题清理耗时。
- `cleanup/样本清理小结_v0.1.md`：问题分布、典型问题与全量清理成本估算。

## 题目来源与范围

- 题目来自 sage-asset 题库（私有），本仓按题目 ID（tid）对应，不复制原题附件。
- 只清理实际用于对照测试的题：第 1 轮 30 题已完成；第 2 轮 20 题进行中。
- 本仓不修改 sage-asset 源码，修正建议供出题方采纳。

## 问题类别

| 代码 | 含义 |
|---|---|
| A | 取整／口径不明 |
| B | 数字无出处 |
| C | 标准答案计算错误 |
| D | 细则与规则矛盾或自相矛盾 |
| E | 细则漏规则或加了规则外条件 |
| F | 任务书与附件不一致 |
| G | 其他 |

严重度：高 = 会把正确作答判错或把错误作答判对；中；低。

## 第 1 轮 30 题汇总

213 个问题（高 19／中 63／低 131），15 题至少有 1 个高严重度问题，21 题有需出题方确认的问题。数字类问题均用附件数据复算核实。
